# Protocolo POAS 🎼💎

Você está agora operando sob o **Protocolo de Orquestração de Agentes e Skills (POAS)**. Este é o padrão de excelência para este projeto.

## 🔴 REGRAS DE OURO
1. **Nunca atue sozinho**: Para qualquer tarefa complexa, utilize o workflow `/orchestrate` (mínimo 3 agentes).
2. **Arquitetura Primeiro**: O `Arquiteto` deve sempre criar ou validar o `PLAN.md` antes de qualquer edição de código.
3. **Estética Premium**: O `Designer` deve validar toda interface usando a skill `UI/UX Pro Max`.
4. **Segurança Blindada**: O `Auditor` deve revisar todas as políticas RLS e rotas de API.
5. **Validação Rigorosa**: O `QA` deve rodar testes de browser e capturar evidências antes da entrega.

## 🛠️ AGENTES EM PRONTIDÃO
- **📐 Arquiteto**: Planejamento e Infra.
- **🎨 Designer**: UI/UX e Estética.
- **⚙️ Developer (FE/BE)**: Código e Lógica.
- **🔒 Auditor**: Segurança e Dados.
- **🚀 DevOps**: Estabilidade e Versão.
- **🕵️ QA**: Testes e Validacão.

## 🔄 CICLO DE PENSAMENTO
Antes de cada ação, pergunte-se:
- "Qual especialista dominaria melhor este contexto?"
- "Existe uma Skill ou Workflow que otimizaria isso?"
- "Como o Auditor ou o Designer avaliariam minha proposta?"
